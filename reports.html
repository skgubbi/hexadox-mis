HEXADOX MIS — SALES REPORTS

Report Filters

ABM/Admin can select All HQs. Other users can see only their assigned HQs.

1. HQ-wise Product-wise Primary and Secondary Sales

Shows Primary Quantity, Primary Value, Secondary Quantity and Secondary Value.
Select filters and click GENERATE REPORT.

2. HQ-wise Product-wise Achievement Report

Achievement % is calculated as achievement value ÷ target value × 100. When All HQs is selected, the bottom row is ABM TOTAL.
Select filters and click GENERATE REPORT.
