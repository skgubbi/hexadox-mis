HEXADOX MIS — SALES REPORTS

Report Filters

All reports use the same Start Month → End Month period. With All HQs selected, every product is consolidated across all HQs and shown as ABM TOTAL.

1. HQ-wise Product-wise Primary and Secondary Sales

Primary and Secondary quantities and values are consolidated by HQ and Product for the selected period. Values are calculated from the PTS stored with each submitted transaction.
Select filters and click GENERATE REPORT.

2. HQ-wise Product-wise Achievement Report

Achievement percentages are calculated from Target Units against consolidated Primary and Secondary Units for the selected period.
Select filters and click GENERATE REPORT.

3. HQ Monthly Cumulative Value Achievement

Monthly target and sales values are shown only for the selected Start Month → End Month period.
Select filters and click GENERATE REPORT.
